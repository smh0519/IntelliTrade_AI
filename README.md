# 📈 IntelliTrade AI - Advanced Quant Trading Bot

이 프로젝트는 Python 기반의 자동 매매 시스템으로, 하이브리드 멀티 전략(Multi-Strategy) 병렬 처리, 강력한 자산 방어 기제(Risk Management), 그리고 **미국 증시와 100% 동기화되는 안전한 실시간 모의투자(Paper Trading) 인프라**를 갖춘 실전형 퀀트 봇입니다.

---

## 🌟 핵심 기능 (Key Features)

### 1. 실시간 페이퍼 트레이딩 엔진 (Zero-Risk Simulation)
내 소중한 돈을 당장 넣을 필요가 없습니다. 봇 내부에 탑재된 '가상 장부 엔진'이 시장의 현재 가격을 실시간으로 추적하며 가상 매매를 진행합니다.
* **리얼타임 가격 동기화**: `yfinance`를 통해 생성된 가짜 난수가 아닌, 미국 현지 거래소의 실제 체결가를 실시간 속도로 조회하여 타점을 읽습니다.
* **현실적인 슬리피지(Slippage) 페널티**: 가상 매매의 수익률 거품을 막기 위해 0.05%의 매수/매도 수수료 및 슬리피지가 장부에 엄격하게 적용됩니다.
* **영구 상태 보존**: 봇을 중간에 껐다 켜도, 저장된 JSON 장부 파일을 통해 언제든 내 1만 달러 투자 진척도와 평단가를 이어서 불러옵니다.

### 2. 계층형 포트폴리오 대시보드 (CLI Dashboard)
단순한 텍스트 로그의 딱딱함을 벗어나, 매 1분마다 타점 검사 전 내 자산 상태를 우아한 표 형태로 터미널에 그려줍니다.
* **계층 구조화**: `[전략 A] -> [애플] -> [150달러 평단가로 5주 매수]` 구조로 철저하게 분리되어, 어느 전략이 돈을 벌어다 주고 있는지 완벽하게 분리 추적합니다.
* **물타기 비용(가중평균) 자동 합계**: 추가 매수 시 평단가를 자동으로 갱신해 주며, 현재 시세와 대조하여 직관적인 수익률(%, 🟢/🔴)을 실시간 렌더링합니다.

### 3. 멀티 전략 3대 병렬 아키텍처 (Router System)
이 봇은 3개의 독립적인 퀀트 지표 전략이 한 계좌 안에서 서로 자금을 빼앗지 않고 동시에 구동됩니다.
* **[STRAT_A] 래리 윌리엄스 돌파 (Classic)**: 변동성 돌파 타점 계산 + 타임컷 포지션 청산.
* **[STRAT_B] 하이브리드 추세 돌파**: 돌파 로직 + 20일선 상승장 확인 + 전일 거래량 폭발 조건 충족 시 진입.
* **[STRAT_C] 낙폭 과대 스윙**: 대세 상승장 필터(S&P500 200MA) + 볼린저 밴드 하단 이탈 + RSI 30 미만 돌입 시 역추세 매수.

## 🛡 실전형 방어 가이드라인 (Defense Mechanisms)

1. **오버나잇 배제 (Timecut)**
   * 뉴욕 현지 시각 오후 3시 55분이 되면, 변동성 높은 오버나잇 전략으로 묶인 종목들은 전부 강제 대피 시장가 청산을 시행합니다.
2. **대세 하락장 접근 금지 (Macro Filter Lock-on)**
   * S&P 500(`SPY`)의 일봉 추세선이 하락장을 지목하면, 바닥을 잡으려는 모든 역추세 로직을 동결시켜 '떨어지는 칼날'에 손이 베이는 것을 막습니다.
3. **일일 종목 매수 횟수 제한 (Overtrading Prevention)**
   * 최악의 횡보장에서 속임수 패턴(휩쏘)에 당해 기계적으로 수십 번 거래하며 계좌가 갈리는 것을 막습니다.
4. **미체결 주문 락업(Lock-up) 방벽**
   * 증권사에 쏜 주문이 3분 이상 미체결 상태라면 타임아웃 강제 취소를 발동하여 다음 타점을 위한 예산을 복귀시킵니다.

## 📁 프로젝트 구조 (Directory Structure)

```text
quant_bot/
├── main.py                     # [진입점] 분 단위 봇 가동 (시작 시 대시보드 1회 즉시 스캔)
├── config.py                   # [설정 센터] 뉴욕 시간대 세팅, 자산 분배 및 전략 파라미터 제어
├── quant_logic.py              # [핵심 로직] 멀티 전략 평가 및 트리형 대시보드 렌더링 엔진
├── data/
│   └── mock_account.json       # [가상 장부] 시뮬레이션용 데이터베이스 파일 (평단가/수량 영구 백업)
├── utils/                      
│   ├── mock_account.py         # 실시간 물타기 평단가 계산 기능을 포함한 계층형 장부 DB 제어기
│   ├── broker_api_client.py    # 증권사 통신 클라이언트 (페이퍼 트레이딩 모드 라우팅 포함)
│   ├── market_data.py          # 과거 캔들 데이터 엔진
│   ├── indicators.py           # 수학적 보조지표(RSI, MA, BB 등) 계산 모듈
│   └── logger.py               # 콘솔 출력 및 trading_bot.log 백업 모듈
└── .env                        # [보안 파일] API Key 및 IS_SIMULATION_MODE 상태 환경 변수
```

## 🚀 시작하기 (Getting Started)

1. **환경 세팅**:
   Python 내 필수 분석 패키지를 설치합니다.
   ```bash
   pip install requests python-dotenv schedule pandas numpy ta yfinance
   ```

2. **미국 증시 시간 및 모의투자 활성화 세팅 (.env)**:
   루트 디렉토리의 `.env` 파일에 모의투자 여부를 켜둡니다 (`config.py`의 뉴욕 시간대를 본 봇은 자동으로 시차를 계산합니다).
   ```env
   IS_SIMULATION_MODE="true"
   # 아래는 실 거래 전환 시 사용할 변수입니다.
   # BROKER_API_KEY="YOUR_KEY"
   ```

3. **가동 명령 (Startup)**:
   ```bash
   python main.py
   ```
   *터미널 창에서 주기적인 실시간 대시보드 화면 렌더링을 감상하실 수 있습니다.*
