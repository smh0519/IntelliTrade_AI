# 🚀 Quant Trading System (퀀트 자동 매매 시스템)

이 프로젝트는 Python을 기반으로 하는 주식 자동 매매 시스템의 기본 프레임워크를 제공합니다.
다양한 거래 전략을 플러그인 방식으로 적용하고, 증권사 API를 통해 실제 매매를 실행할 수 있도록 설계되었습니다.

## 🌟 주요 기능

-   **설정 관리**: `.env` 파일을 통한 민감 정보 관리 및 `config.py`를 통한 일반 설정 관리.
-   **데이터 관리**: 증권사 API를 통해 실시간 및 과거 데이터 조회.
-   **전략 모듈화**: 새로운 전략을 쉽게 추가할 수 있는 구조.
-   **포트폴리오 및 위험 관리**: 보유 종목, 현금, 손익 관리 및 위험 규칙 적용.
-   **주문 실행**: 매수/매도 주문 실행.
-   **로깅**: 모든 시스템 활동을 기록하여 모니터링 및 디버깅 용이.
-   **스케줄링**: 특정 시간에 자동 매매 로직 실행.
